# 前端交互修复记录

日期：2026-09-26。范围：`app/src/client` 当前桌面前端。保留工作区中已有的 Tauri 迁移和其他未提交修改。

## 已修复

| 场景 | 原问题 | 修复后的行为 |
| --- | --- | --- |
| 聊天输入与工具菜单 | 工具使用过期的父级输入，可能覆盖正在输入的草稿；输入法回车可能触发操作 | 工具读取当前草稿；忽略输入法确认事件；显式发送后正确清空 |
| 生成中的后续输入 | 输入文字后停止按钮消失；附图发送可能打断当前运行 | 持续提供停止入口；附图在运行结束后发送，保留草稿 |
| 消息队列 | 删除、清空失败仍移除本地消息；尚未完成入队即可操作；已被消费的消息可能被重复插入 | 失败保留消息并提示；串行处理冲突操作；识别已经消费的消息 |
| 会话切换与删除 | 重复操作、失败和迟到响应可能造成状态混用 | 操作期间锁定输入；失败恢复可操作状态；忽略旧会话响应；删除当前会话后清理旧的审批、队列和计划状态 |
| 模型选择 | 较慢的旧供应商请求覆盖新供应商模型列表 | 清空过期选项，使用请求序号防止响应倒序覆盖，提供失败重试提示 |
| 文档保存 | 保存前即取消未保存标记；批量保存漏写；保存期间的新编辑被错误标记为已保存 | 只对写入成功的提交版本更新基线；部分失败单独保留；继续输入的版本仍显示未保存 |
| 文档读取与草稿 | 读取失败呈现可编辑空文件；占位内容进入缓存；快速离开时丢失防抖中的草稿 | 读取成功前只读，支持重试；只缓存实际编辑内容；卸载和离开页面时保存草稿，支持有意清空的内容 |
| Agent 与项目切换 | 后端失败后界面仍切换选中项；旧轮询覆盖新状态 | 成功后再更新选择；忽略过期轮询；显示可关闭的错误提示 |
| 设置页 | 切换页面丢失未保存配置；隐藏设置页仍处理 Escape | 保留已访问的设置页和草稿；隐藏时停用快捷键；重新进入只刷新运行信息 |
| 文件夹选择 | 快速浏览时旧请求覆盖新目录；重复提交；失败无反馈 | 忽略过期目录响应，限制冲突操作，并提供加载和失败状态 |
| 审批与弹窗 | 多张审批卡同时响应数字键；重复提交；弹窗焦点逃逸 | 仅焦点所在审批卡响应；提交失败可重试；对话框循环管理 Tab 焦点，关闭后还原焦点 |
| 终端 | 旧连接消息污染新终端；切换或卸载后仍重连；停止失败被当作成功 | 只接受当前连接回调；取消过期重连；停止失败保留状态并提示，避免错误重启 |
| 插件与主动对话 | 插件 HTTP 失败无反馈；主动对话错误流被忽略，错误被轮询立即清除 | 检查响应状态，保留插件现状；主动对话恢复失败输入并保留错误提示 |
| 全局快捷键与工具卡 | Shift+Tab 改变权限；隐藏聊天抢快捷键；未知工具名显示为终端 | 恢复标准焦点导航；快捷键尊重页面可见性、输入法和弹窗；显示实际工具名称 |

## 回归验证

浏览器测试位于 `scripts/interactions.test.ts`。测试先打包真实 React 组件，再通过 Chromium 执行点击、输入、快捷键及延迟/失败请求。后端接口、文件写入、终端连接和模型流使用受控替身，测试不会调用真实模型或修改实际项目文件。

```sh
cd app
pnpm exec playwright install chromium  # 首次运行时安装测试浏览器
pnpm run test:interactions
pnpm exec vite build --configLoader runner
pnpm exec tsx --test --test-reporter=tap $(rg --files src/client | rg '\.test\.ts$')
pnpm exec tsc -p tsconfig.client.json --noEmit
pnpm exec tsc -p tsconfig.sdk.json --noEmit
```

验证结果：

- Chromium 交互回归：21/21 通过，无未捕获页面异常。
- 全量前端测试：553/553 通过，包含新增的聊天/终端停止接口失败测试。
- 前端、公开 SDK、浏览器测试代码的 TypeScript 检查通过。
- 生产构建通过。主包和 CodeMirror 包仍有既有的 500 kB 体积提示。
- 构建产物的首屏依赖与桌面传输复核：9/9 通过，CodeMirror/xterm 仍保持延迟加载。
- `git diff --check` 通过。

本机 Vite 默认配置打包加载器出现等待不返回，生产构建使用 `--configLoader runner` 完成。配置路径改用标准 ESM 的 `import.meta.url`，兼容该加载方式，并保留原来的入口、分包和相对资源路径。
