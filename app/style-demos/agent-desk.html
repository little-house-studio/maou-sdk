当前摊开

项目是文件夹，agent 是里面的人。当前项目反相摊开，其它项目只占两行。 没有下拉，没有树轨，没有要学的符号。 窗格 · 图示四案 · 左栏脊椎 · 对照旧四案 · 目录

纸

我会这样排

侧栏上半只回答两件事：我在哪个项目，我在跟谁说话。 下半还是会话。项目区按内容长，不锁 24% 空白。

层级 项目是第一层。只有当前项目底下挂 agent。其它项目不展开，所以不会出现「四个项目各自一棵树」。
学习 没有 ▾、没有 + 藏在角上、没有「先开菜单再选」。想换项目就点那一行，想换人就点名字。
一眼 黑条 = 你在的项目。左墨条 = 你在聊的 agent。路径只跟项目走，不跟 agent 重复。
视觉 纸面壳：反相、左条、12px 近黑路径。名称和路径分开，不靠透明度洗字。
交互 点项目 → 进这个工作区并落到主 agent。点 agent → 只换人。最底下「+ 增加项目」始终在流里，裁不到。

这页故意不做的：

  • 下拉切换器：层级进了菜单，路径还被 24% 高裁掉。
  • 文件树竖线：agent 不是文件，轨线占宽、像资源管理器。
  • 每个项目都摊开：四份 coding 并排，分不清「我在哪」。

只是方案演示，没有改生产侧栏。点左边可以切换项目、agent、系统 / IM。
