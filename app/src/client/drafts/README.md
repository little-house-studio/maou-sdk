# UI 草稿站

独立页面：`/draft.html`（`main-draft.tsx` → `DraftShell`）。

**布局分区**按产品草图；**视觉**深灰底 + 薄荷绿重点色；**逻辑用图标扫读**（状态形状、角色头像、父子层级标记、文件类型 SVG、顶栏/底栏 chrome 图标），文字作补充。色调 + 形状双通道，不只靠颜色。

```
模式：聊天 | 项目 | Team

聊天：
┌ 模式 · token · 文件 ────────────────────────────┐
├ agent ──┬ 上下文 / Tasks / Composer ┬ 文件树 ──┤
│ 会话    │                            │          │
├─────────┴────────────────────────────┴──────────┤
│ 终端 · 待办 · 日志                              │
└─────────────────────────────────────────────────┘

项目：
┌ 模式 · token ───────────────────────────────────┐
├ 最近页签 ───────────────────────────────────────┤

```

## 项目模式（真实可用性）

| 区域 | 能力 |
|------|------|
| 文档 | 树筛选、脏点、侧栏折叠、**⌘P 快速打开**、祖先目录自动展开、活动文件滚入视野 |
| 大纲 | 筛选 · Alt/双击跳画布节点 · ⌘↵ 画布聚焦 |
| 页签 | 最近文档 MRU、脏标、关闭、**⌘W**、⌥[/]、⌘⇥ |
| MD | CodeMirror 源码 · 预览 · 分栏拖宽 · **⌘F** 文内查找 · + 标题 |
| 画布 | Tab/`\` 生长 · 连线 · 撤销 · 吸附 · 滚轮平移 · Mermaid |
| 脏状态 | MD/画布分标、改动计数、同步 / 全同步、重置、清会话 |
| 会话 | `sessionStorage` 持久化草稿 + **最近页签**；关页有未保存时浏览器提示 |

### 常用快捷键

- **⌘S** 同步当前 · **⌘⇧S** 全同步 · **⌘F** 文内查找 · **⌘P** 打开文档 · **⌘W** 关页签  
- **⌥1–4** 分栏 / 预览 / 源码 / 画布  
- 画布：**Tab** 深度 · **\\** 广度 · **Del** · **⌘Z** · 滚轮平移 · ⌃滚轮缩放  

## 预览

```bash
cd app && pnpm run dev
```

桌面窗口顶栏点 **「项目」**。草稿页在开发时由 Electron 加载 Vite；浏览器直接打开会被拒绝。
