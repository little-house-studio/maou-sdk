# 简介
- 可以作为原生通信接口使用，支持发送和接收信息，通过特定的端口号通信
- 很重要的拓展接口，非常大一部分的插件拓展都要走这个

# 结构体
## 信封
    - v：版本协议（可选，默认最新版）
    - type：发送消息/控制指令/获取返回数据
    - data：调用时间
    - agnet：发送给谁
    - session：发送给哪个会话记录
## agent消息类
    - 使用和一样agent 一样的消息结构体，直接复用 
    - 作用是发给agent附带的消息
    - name：发送者名字，消息使用<message name="name">content</message>包裹内容
    - content：发送的文本是一个结构体数组，也可以是单条文本
    - image：图片附件（可选）
    - video：视频附件（可选）
    - audio：声音附件（可选）
    - command：附带发送的指令，例如"goal"
    - send_mode：发送模式（队列，插入，停止并发送）
## 系统控制类
    - 发送空消息
    - 停止
